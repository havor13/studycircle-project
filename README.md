# studycircle-project  📚

StudyCircle is a collaborative learning platform designed to make group study easier, more interactive, and more engaging. It helps students connect, share resources, and learn together in real time.

---

## ✨ Features Implemented So Far
- 🔑 **User Authentication** – Secure sign-up and login system
- 💬 **Chat System** – Real-time messaging between study group members
- 👥 **Group Creation & Management** – Create study circles, invite members, and manage participation
- 📂 **Resource Sharing** – Upload and share notes, links, and documents
- 📊 **Progress Tracking** – Monitor study sessions and group activity
- 🎯 **Simple UI** – Clean and intuitive interface for focused learning
